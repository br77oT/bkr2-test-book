Multivoice Test Book
====================

A self-contained copy of this book. Nothing needs to be installed.

TO READ IT
Open index.html in any modern browser (double-clicking works).

It also works served over http if you would rather host it:

    python3 -m http.server 8000

AUDIO: 1 section(s) include narration. Press Space to play;
the text highlights in time with it.

Keyboard: Space play/pause, arrows skip sentences, +/- change speed.
